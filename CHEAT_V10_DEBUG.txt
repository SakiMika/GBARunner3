GBARunner3 cheat v10 diagnostic build

The lower screen displays boot checkpoints from gbaRunnerMain through VirtualMachine::Run.
The last visible checkpoint identifies the operation that did not return. Older lines scroll upward automatically.

When a ROM has cheats, [CHEAT] stays at the lower-right after boot.
The FIRST press of [CHEAT] clears/hides the boot log and opens the normal cheat menu.
After the menu closes, the log remains hidden and only [CHEAT] is shown.

Key checkpoints:
22 CHEAT LOAD >     entering cheat JSON loader
23 CHEAT LOAD OK    cheat JSON loader returned with cheats
24 CHEAT NONE       loader returned but found no matching cheats
44 CHEAT UI >       entering cheat UI initialization
45 CHEAT UI OK      cheat UI initialized
50 VM RUN >         about to enter the GBA virtual machine
!! VM RETURNED      VM unexpectedly returned
!! MOUNT FS FAILED  filesystem mount failed
