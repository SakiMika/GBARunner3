Cheat v3 ARM9 linker fix
=========================

Root cause addressed:
- CheatService.o was intentionally moved to EWRAM at 0x0204xxxx in v2.
- Most ARM9 executable code remains in VRAM around 0x0680xxxx.
- That separation is larger than the +/-32 MiB range of a normal ARM BL.
- Calls from CheatService to FatFs/libnds/libtwl/core functions could therefore
  fail at the final arm9.elf link with R_ARM_CALL/R_ARM_JUMP24 relocation errors.

Fix:
- Compile CheatService.o with -mlong-calls using a target-specific Makefile flag.
- Keep the rest of the project unchanged, so there is no global performance cost.
- Retain the v2 lightweight JSON parser/tile UI/EWRAM placement.

The REG_* redefinition messages from libtwl shown in the GitHub log are warnings
and are unrelated to the final collect2 failure.
