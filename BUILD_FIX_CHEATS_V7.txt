GBARunner3 cheat support v7 - splash hang fix
==============================================

Runtime failure in v6:
- Binary built and reached the GBARunner3 splash screen, then appeared to hang.

Root cause addressed in v7:
- ARM9 normal stack size is DTCM_STACK_SIZE = 1024 - 32 = 992 bytes.
- CheatService::TryLoadFile() placed a FatFs FIL on that stack. With FF_FS_TINY=0,
  FIL includes BYTE buf[FF_MAX_SS] (normally 512 bytes).
- The same function also allocated a temporary Cheat (~hundreds of bytes), JSON
  key/code buffers, while LoadForRom() contributed a 64-byte path buffer.
- This can overflow the ~992-byte boot stack exactly while the splash is shown.

Changes:
1. FIL cheat file object moved to .ewram.bss.
2. Cheat path/key/code parsing buffers moved to .ewram.bss.
3. JSON is parsed directly into _cheats[_cheatCount]; no large temporary Cheat.
4. CodeLine parsing writes directly into the final code slot.
5. Initial touch-down state is latched when the cheat UI initializes so a held or
   stale startup touch cannot immediately enter the modal cheat loop.
6. Existing v5/v6 BSS/linker and ARM7 touch API fixes are retained.
